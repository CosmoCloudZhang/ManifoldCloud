# Archive

Records of the overnight pipeline build of 25 November 2026, kept as a history of how the first version was made, including the instructions given to the AI coding assistant that wrote it.

They describe the repository as it was then. The environment names (`CosmoConda`, `.venv`, `umapz`), module locations and script paths in these files have since changed; the current instructions are in the top-level `README.md` and `documents/`. Machine-specific paths were replaced by `<repository>`, `<conda>` and `~`.
